## Headline: M49 merge codes-hash fast path (measured via M51 cell)

The M49 `merge` codes-hash fast path triggers when both frames key on a
`ColumnCategorical` with identical `categories[]` orderings: the join
hashes the i64 codes instead of coercing to strings.  M48's
`merge_cat_via_strings` cell merged two `astype("category")` frames on
pandas but plain str frames on StrictPy — it never exercised the codes
path.  `merge_cat_codes` closes that gap.

## Methodology notes

- `merge_cat_codes` builds the categorical key on both StrictPy frames
  via `tabular.col_categorical_ordered(values, cats)`, with `cats`
  derived by a first-appearance dedup of the (null-filled) category
  column so both frames share a bit-identical `categories[]` list — the
  precondition for the M49 codes-hash path.  The pandas comparand casts
  the key to a fixed-ordering `pd.CategoricalDtype` before merging.
- All other M48/M49 cells are unchanged by M51.
